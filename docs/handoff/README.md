# Handoffs

One entry point for whoever comes next, human or agent: what is current, what
is history, what is still open, and who owns each open question.

- Active handoffs sit here. Superseded ones move to `archive/` with a line at
  the top saying what replaced them.
- Never edit someone else's handoff. Reply with a new one in your own
  direction.
- Use `_template.md`.

The standing record of who owns which paths, and the running log between the
two agents, is `COORDINATION.md` at the repository root. A handoff is for a
piece of work; the coordination file is for the day to day.
